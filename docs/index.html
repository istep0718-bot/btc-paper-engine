年別の実現損益

決済時刻（日本時間）の年ごとに集計しています。含み損益（未決済の評価損益）は課税対象ではありません。ポジションを決済して利益・損失が確定した時点で、初めてその年の所得として課税対象になります。

税金メモ（日本の現行ルール）

・所得区分：個人の暗号資産取引の利益は原則「雑所得（その他）」で、給与などと合算する総合課税です。先物（無期限契約など証拠金取引）の損益も同様に総合課税です（国税庁FAQ 2-2、2-12）。
・税率：所得税は所得に応じて5%〜45%の累進税率、住民税は原則10%、さらに復興特別所得税として所得税額の2.1%が加算されます（〜2037年）。最大で約55.945%。
・損失の扱い：雑所得の損失は、給与所得など他の所得と損益通算できません。また、翌年以降への繰越控除も現行制度ではありません。その年の暗号資産同士の利益・損失は同一年内で相殺されます（国税庁FAQ 2-11）。
・20万円ルール：給与を1か所から受ける給与所得者は、給与・退職以外の所得の合計が20万円以下なら所得税の確定申告は原則不要です。ただし、所得税の申告が不要でも住民税の申告が必要な場合があります。また他の理由で確定申告をする場合は20万円以下の所得も申告が必要です（国税庁 No.1900）。
・円換算：外貨建ての損益は、取引（約定・決済）時点の為替レートで円に換算するのが原則です。このダッシュボードでは便宜上、現在の換算レート（--）を全期間に一律適用しているため、実際の申告額とは差が出ます。
・将来の改正：令和8年度税制改正で、国内の暗号資産取引業者を通じた「特定暗号資産」等の取引について、税率20.315%（所得税15%＋復興0.315%＋住民税5%）の申告分離課税と、損失の3年間繰越控除が導入されることが決まりました。適用は改正金商法の施行日の属する年の翌年1月1日以後の取引からで、現在の見込みでは2028年1月1日開始です。なお、このBOTが使う海外取引所（Hyperliquid）は分離課税の対象業者には当たらない見込みで、その場合は改正後も現行の総合課税が続く見通しです。
